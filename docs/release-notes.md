## 桌面侧边栏（中文版）稳定版发布

> 基于 [bitlamas/gtt-sidebar](https://github.com/bitlamas/gtt-sidebar) 改造的中文版 Windows 桌面侧边栏。
> `.NET Framework 4.7.2` ｜ 免安装 ｜ **无需任何 API Key**

---

### 本版亮点

**失去焦点贴边隐藏**

侧边栏失去焦点后自动滑出屏幕外，只留 3px 边缘用于鼠标感应。

- 延迟 600ms 后滑出（可调 0–2000ms），鼠标触碰屏幕边缘中段即自动滑回
- 感应区默认避开屏幕顶部 25%（不遮挡窗口右上角关闭按钮）与底部 15%（不遮挡任务栏），比例可调
- 设置窗口、备注弹窗、图标选择器打开期间自动抑制隐藏
- 托盘图标双击亦可唤回

**当月日历卡片（含中国法定节假日）**

- 月历网格，今日高亮；放假日标红、调休上班日标灰，悬停显示节日名
- 底部显示下一个节假日与倒数天数
- 启动拉取一次 + 每 24 小时刷新；四级数据源降级 + 本地缓存，离线可用

**系统信息卡片**

- 上半部实时负载：CPU / 内存 / 延迟，支持告警阈值染色、悬停查看 5 分钟与 1 小时均值
- 下半部本机信息：运行时长、磁盘可用、网络速率、进程数

**全量中文界面**

主窗口、设置窗口、图标选择器、备注弹窗、托盘菜单、全部消息框与各组件可见文字均已汉化，日期改为「2025年1月1日 星期三」格式。

**天气改用 Open-Meteo（重要）**

彻底移除原版中硬编码的第三方 OpenWeatherMap 密钥，改用免注册的 Open-Meteo，支持中文城市名，**本版无需任何 API Key**。

---

### 相对原版的改动

| 项目 | 说明 |
|---|---|
| 新增组件 | 日历（含节假日）、系统信息 |
| 停用组件 | 行情（数据源不可用）、独立系统监控（已合并进系统信息卡片） |
| 修复缺陷 | 原 `csproj` 中 `ShortcutsWidget.xaml.cs` 重复声明导致 `MSB3105` 编译失败 |
| 程序更名 | 产物 `gtt-sidebar.exe` → **`DesktopSidebar.exe`**，数据目录同步改为 `%APPDATA%\DesktopSidebar\` |
| 快捷方式汉化 | 默认 8 项中文化（计算器 / 文件资源管理器 / 画图 / …），已有配置自动迁移，用户自定义项不受影响 |

---

### 安装与运行

1. 下载下方 Release 资产并解压到任意目录
2. 双击 `DesktopSidebar.exe` 运行，**无需安装**

最小可用文件（两个文件需同目录）：

```
DesktopSidebar.exe
Newtonsoft.Json.dll
```

> 同目录的 `DesktopSidebar.exe.config` 建议保留（仅 183 字节），用于声明所需的 .NET 运行时版本。

**系统要求**：Windows 7 SP1 及以上 + .NET Framework 4.7.2

---

### 升级提示

- 从**原版 gtt-sidebar**升级：数据目录已改为 `%APPDATA%\DesktopSidebar\`，不会自动继承原目录数据，属全新初始化
- 配置新增字段向后兼容，旧配置文件缺字段时自动套用默认值，**无需手动修改**

---

### 已知限制

- 仅支持单显示器主屏（贴边判定基于主屏分辨率）
- 节假日数据依赖第三方公开整理源，若次年安排尚未公布，倒计时会显示「暂无更多假期」（属正常）
