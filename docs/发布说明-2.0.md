# DesktopSidebar 2.0 发布说明（界面重构版）

> **版本：v2.0.0** ｜ 发布日期：2026-10-29
> 基于 [bitlamas/gtt-sidebar](https://github.com/bitlamas/gtt-sidebar) 改造的中文版 Windows 桌面侧边栏
> 上一版本：[v1.0.0 发布说明](发布说明.md)

---

## 一、版本概览

2.0 是一次以**界面与交互**为核心的版本：

| 主题 | 一句话概括 |
|---|---|
| 🎨 设计系统 | 全部界面重构为统一的浅色卡片风，样式令牌集中管理 |
| 🔌 组件插件化 | 侧边栏内容全部插件化，设置窗口可视化启用 / 停用 / 排序，即时生效 |
| 🫥 悬浮胶囊把手 | 收起形态从「贴边小球」升级为彩色描边胶囊把手，可拖动、可悬停展开 |
| 📐 布局修正 | 修复系统信息显示不全、快捷方式双重滑条等多处布局缺陷 |

功能层面（日历 / 天气 / 备注 / 快捷方式 / 系统信息等）与 1.0 保持一致，无破坏性变更，**旧配置自动兼容，替换 exe 即可升级**。

---

## 二、界面重构：统一设计系统 ⭐

新增 `Core/Themes/DesignSystem.xaml` 设计令牌字典，挂在 `App.xaml` 全局资源下，主窗口、设置窗口、托盘菜单、全部组件共享同一套视觉语言：

| 令牌类别 | 内容 |
|---|---|
| 颜色 | 窗口底 `#F2F4F7` 浅灰、卡片纯白、三级文字灰阶、强调色 `#4A90E2` 蓝、状态色（成功 / 警告 / 危险） |
| 圆角 | 卡片 12px / 小元素 8px / 胶囊全圆 |
| 字号 | 大数字 22 / 标题 13 / 正文 11 / 注释 9.5 |
| 控件样式 | 卡片边框、主/次按钮、图标按钮、滑块、复选框、分区标签、字段标签、提示文字 |

**整体风格**：浅灰底 + 白色卡片 + 12px 圆角 + 细边框 + 柔和阴影；侧边栏宽度由 122px 增至 **144px**，内容呼吸感更好。

**设置窗口同步重构**：所有按钮、滑块、复选框、滚动条（6px 圆角细滑块）统一套用设计系统，与侧边栏视觉完全一致。

---

## 三、组件插件化 ⭐

侧边栏内容全部插件化，新增组件只需实现 `IWidget` 接口（含中文名 `DisplayName` 与描述 `Description`），框架**反射自动发现**，主窗口代码零改动。

**设置窗口新增「组件」分组**，每个组件一行：勾选框 + 中文名 + 说明 + ▲▼ 排序箭头。

| 能力 | 说明 |
|---|---|
| 启用 / 停用 | 勾选框即时切换，侧边栏对应卡片立即出现 / 消失 |
| 自定义排序 | ▲▼ 箭头调整顺序，侧边栏同步重排 |
| 即时生效 | **无需重启程序**，配置即时落盘 |
| 新组件默认开启 | 未在配置中记录的组件视为启用，装了就可见 |

> 对比 1.0：组件列表原本是编译期固定的，顺序、开关都不可调；2.0 起全部运行时可配。

---

## 四、悬浮胶囊把手 ⭐

失焦收起形态从圆形悬浮球升级为**竖向胶囊把手**（20×62px），默认启用：

- **彩色渐变描边**：蓝 `#4A90E2` → 青绿 `#3DD8C0` → 紫 `#9B6BF5` 斜向渐变，1.2px 细线绕胶囊一圈；白色渐变底 + 同色系柔和投影 + 三条抓握横线
- **贴边留距**：与屏幕边缘保持 6px 间距，完整呈现胶囊圆角与投影
- **交互**：悬停 600ms 或点击展开侧边栏；按住可上下拖动，位置自动记忆；右键弹菜单（设置… / 退出）
- 展开不抢焦点，收起带 400ms 防抖，不会出现「收起→立刻展开」死循环

传统贴边隐藏模式（滑出屏幕仅留 3px 感应边）仍然保留，可在设置窗口切换。两种模式均修复了 1.0 后期的多个自动隐藏缺陷（开机自启宽限期失效、边缘反复跳变、只隐藏一次等）。

## 五、布局修正

| 问题 | 修复 |
|---|---|
| 系统信息卡片内容显示不全 | 改为**单列「标签左 + 数值右」**布局，7 项信息（CPU / 内存 / 延迟 / 运行时长 / 磁盘可用 / 网络 / 进程数）完整展示，不再截断 |
| 快捷方式卡片内部出现滚动条 | 移除卡片内层 ScrollViewer，**卡片高度随快捷方式个数自然增长**；滚动只保留在最外层侧边栏 |
| 设置窗口「双重滑条」 | 删除快捷方式设置区的内层滚动容器，全应用只保留最外层一个滚动入口 |
| 组件内布局硬编码宽度 | 改为按 `ActualWidth` + `SizeChanged` 动态计算，窗口宽度变化时自适应 |

## 七、升级说明

| 场景 | 说明 |
|---|---|
| **从 v1.0 升级** | 直接替换 exe + `Newtonsoft.Json.dll` 即可，配置向后兼容，**无需修改任何配置文件** |
| 配置新增字段 | `Widgets`（组件启用与排序）、`UseFloatingBall` / `FloatingBallY`（胶囊把手）等新字段自动套用默认值 |
| 自动隐藏行为 | 默认收起形态变为胶囊把手；如偏好 1.0 的贴边隐藏，在设置窗口「窗口与布局」区关闭「悬浮球」即可 |

---

## 八、已知限制

- 仅支持**单显示器主屏**（贴边与把手定位基于主屏分辨率）
- 胶囊把手与贴边隐藏仅支持屏幕左右两侧默认位置
- 全局细滑条样式作用于所有滚动条，个别第三方控件内嵌滚动条外观会随之变化（属预期）
