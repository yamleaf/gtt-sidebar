## 五、一个需要说明的情况：StockWidget

`Widgets/StockWidget/StockWidget.xaml` 与 `.xaml.cs` **文件内容有改动**（汉化 + 货币改人民币），
但**已从 `gtt-sidebar.csproj` 中移除编译注册**，因此：

- 这两个文件**不会参与编译**，代码改动实际不生效
- 源码保留在仓库中，方便将来恢复

若希望保持纯「停用但不改动」的形态，可以把这两个文件**还原为原始内容**
（共 2 处改动：汉化文案、`$`→`¥` 与 USD/CAD→USD/CNY）。

## 七、同步到另一份原仓库时的操作建议

如果你要从原仓库重新拉取、再套用本次改造，需要：

1. **新增**这 6 个源码文件（AutoHideManager + CalendarWidget×3 + SystemInfo×2）
2. **替换**这 26 个修改文件
3. **注意**：`gtt-sidebar.csproj` 有两处关键修改不要遗漏
   - 新组件的 `Compile` / `Page` 注册
   - 删除 `ShortcutsWidget.xaml.cs` 的**重复条目**（否则编译报 `MSB3105`）
4. **不要遗漏** `Core/Interfaces/` —— 它们**不需要改**，避免误改破坏扩展性
