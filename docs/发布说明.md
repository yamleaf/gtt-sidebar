## 二、本版新增功能

### 1. 失去焦点贴边隐藏 ⭐

侧边栏失去焦点后自动滑出屏幕外，只留一条窄边用于鼠标感应。

| 场景 | 行为 |
|---|---|
| 失去焦点 | 延迟 **600ms** 后平滑滑出屏幕，仅保留 **3px** 在屏幕内 |
| 鼠标触碰屏幕边缘中段 | 自动滑回显示 |
| 托盘图标双击 | 唤回显示 |
| 设置窗口 / 备注弹窗 / 图标选择器打开期间 | 自动抑制隐藏，避免操作到一半侧边栏跑掉 |

**可配置项**（设置窗口「窗口与布局」区，托盘右键菜单也有总开关）：

| 配置项 | 默认值 | 范围 |
|---|---|---|
| 启用自动隐藏 | 开 | 开 / 关 |
| 隐藏延迟 | 600 ms | 0 – 2000 ms |
| 触发区顶部留白 | 25% | 0 – 50% |
| 触发区底部留白 | 15% | 0 – 50% |

> 顶部留白用于避开窗口右上角的关闭/最小化按钮；底部留白用于避开任务栏托盘区域。

### 2. 当月日历卡片（含中国法定节假日）

- **月历网格**：7 列、周一起始，今日高亮；放假日标红并带红点，调休上班日带灰点
- **悬停提示**：显示「日期 + 节日名（放假 / 调休上班）」
- **下一假期倒计时**：显示下一个节假日名称与「N 天后 / 明天 / 就是今天」
- **刷新策略**：启动拉取一次，之后每 24 小时刷新；缓存写入 `holidays.json`
- **数据源四级降级**：jsDelivr（holiday-cn）→ fastly.jsDelivr → timor.tech → 本地缓存，离线可用

### 3. 系统信息卡片（含实时负载）

一个卡片同时展示实时负载与本机信息，每 2 秒刷新：

```
系统信息
CPU                     12%     ← 超阈值标红
内存                    58%
延迟                    23ms
────────────────────────────
运行时长            3天 5小时
磁盘可用       128 / 476 GB
网络            无线 866Mbps
进程数                 214 个
```

- **CPU / 内存 / 延迟**：支持告警阈值染色，鼠标悬停可查看「当前值 / 5 分钟均值 / 1 小时均值」
- **运行时长 / 磁盘 / 网络 / 进程数**：本地读取，无网络请求
- 刷新频率沿用「系统监控」设置项（默认 2 秒），改完立即生效

## 三、界面与体验优化

### 全量中文化

覆盖主窗口、设置窗口、图标选择器、备注弹窗、托盘菜单、全部消息框，以及各组件的可见文字。

| 项目 | 改造前 | 改造后 |
|---|---|---|
| 时钟日期 | `January 1, 2025` | `2025年1月1日 星期三` |
| 天气描述 | 英文原文 | 中文映射（含模糊兜底） |
| 默认城市 | Saint-Joseph-de-Beauce | **Hangzhou,CN** |
| 系统监控表头 | `RAM` / `PING` | `内存` / `延迟` |
| 快捷方式默认项 | Calculator / File Explorer … | 计算器 / 文件资源管理器 … |

### 快捷方式默认项汉化（含已有数据自动迁移）

默认 8 个快捷方式：**计算器、文件资源管理器、画图、命令提示符、任务管理器、系统设置、记事本、终端 (PowerShell)**，图标由 emoji 升级为内置 PNG。

> **已有配置会自动迁移**：按英文名精确匹配后改中文名并换图标，自动回写文件。
> 用户自己改过名的快捷方式**不会被误改**。

### 布局调整

- 快捷方式网格改为自适应 **5 列**，8 个默认项正好排成整齐两行
- 备注区高度 175 → **185px**，预览区放宽
- 组件容器外包 **ScrollViewer** 兜底——组件总高度超出屏幕时可滚动，内容不会被裁切

## 四、数据源与依赖调整

### 天气 API 改用 Open-Meteo（重要）

原实现在代码中**硬编码了他人 OpenWeatherMap 密钥**，随时可能被限流或失效。本版彻底替换：

| 对比项 | 旧（OpenWeatherMap） | 新（Open-Meteo） |
|---|---|---|
| API Key | 需要（且是硬编码他人密钥） | **不需要**，免注册 |
| 中文城市名 | 不支持 | **支持**（直接输入「杭州」） |
| 费用 | 免费额度 1000 次/天 | 免费非商用，无额度焦虑 |

**本版无需任何 API Key。**

### 时间显示

时钟使用本地 `DateTime.Now`，**零网络依赖**，不涉及外部接口。

## 七、安装与运行

### 直接运行（推荐）

从 Releases 下载压缩包，解压到任意目录，**无需安装**。

最小可用文件（两个文件放同一目录）：

```
DesktopSidebar.exe
Newtonsoft.Json.dll
```

> 同目录的 `DesktopSidebar.exe.config` 建议保留（仅 183 字节），用于声明所需的 .NET 运行时版本。

### 从源码编译

需要 **.NET Framework 4.7.2** 开发环境，用 Visual Studio 打开 `gtt-sidebar.sln`，生成 Release 配置即可。

首次编译前需还原 NuGet 包（依赖见 `packages.config`）：

```
nuget restore gtt-sidebar.sln
```

## 九、已知限制

- 仅支持**单显示器主屏**（贴边判定基于主屏分辨率）
- 节假日数据依赖第三方公开整理源，若上游未发布次年安排，则次年倒计时会显示「暂无更多假期」（属正常）
- 截图/录屏类工具可能捕获不到贴边隐藏状态下的窗口
